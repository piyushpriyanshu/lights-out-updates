# Lights Out updates

Latest version: **8.4** (24 Oct 2026)

The Lights Out app checks this page and offers new versions by itself.
To install by hand, download [LightsOut-8.4.apk](LightsOut-8.4.apk).

## What's new
- Switch session or Grand Prix without leaving the screen: it loads in the background
- The arrow on the Grand Prix card opens every finished weekend with a replay
- Tabs layout: every tab opens below the tabs, most important first
- Settings: no second title under the top bar
