# Lights Out updates

Latest version: **8.1** (24 Oct 2026)

The Lights Out app checks this page and offers new versions by itself.
To install by hand, download [LightsOut-8.1.apk](LightsOut-8.1.apk).

## What's new
- Live map: the circuit's real lap is fetched in the background during race week, so it is ready before each session
- Replays: best laps leave out deleted laps and in-laps (checked against the official US GP FP1 results)
- Team radio: when F1 asks for a sign-in to play clips, the list shows who radioed and when, without buttons that can't work
