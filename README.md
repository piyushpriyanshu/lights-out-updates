# Lights Out updates

Latest version: **8.2** (24 Oct 2026)

The Lights Out app checks this page and offers new versions by itself.
To install by hand, download [LightsOut-8.2.apk](LightsOut-8.2.apk).

## What's new
- Team radio plays again, live and in replays
- Live commentary: overtakes, pit stops, fastest laps, flags and results as they happen, in step with your stream delay
- Driver faces on the map instead of dots
- A tighter order list: the whole field takes about a third less space
- Small fixes for narrow phones and race control
