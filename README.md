# Lights Out updates

Latest version: **7.0** (13 Oct 2026)

The Lights Out app checks this page and offers new versions by itself.
To install by hand, download [LightsOut-7.0.apk](LightsOut-7.0.apk).

## What's new
- Live Updates: the live session on your lock screen and in the status bar (lap, flags, leader, your driver). Android 16 shows it as a Live Update
- Race reminders become a countdown to the session, and the live session follows when it starts (switch in Settings)
- Fixed: screen titles no longer appear twice (Cheat sheet, Glossary, Rulebook, Saved, Settings, Sources)
- The update pop-up shows the new app icon
