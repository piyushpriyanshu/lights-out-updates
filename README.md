# Lights Out updates

Latest version: **8.0** (23 Oct 2026)

The Lights Out app checks this page and offers new versions by itself.
To install by hand, download [LightsOut-8.0.apk](LightsOut-8.0.apk).

## What's new
- Live map: F1's car positions are used only when they arrive on time; late or patchy ones no longer freeze the map, which follows the live timing instead
- Replays: a clear message while a session is live (the free replay data pauses until 30 minutes after it ends)
