# Lights Out updates

Latest version: **6.8** (12 Oct 2026)

The Lights Out app checks this page and offers new versions by itself.
To install by hand, download [LightsOut-6.8.apk](LightsOut-6.8.apk).

## What's new
- New look: the Lights Out car and lettering from the cover on every screen
- The tab you are on now has a compact red box
- Fixed: tab names no longer appear twice at the top
- Sharper app icon and a new opening animation based on the cover; no more white line at start-up
- Choose how often the app checks for updates (every open, 1, 3 or 6 hours), with a notification when one is out
